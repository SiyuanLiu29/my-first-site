# 今天也没什么特别的

一段普通的聊天。移动端优先的纯前端互动网页，使用 React + Vite，所有剧情和资源随网站静态发布，无后端、数据库或在线 AI 服务。

这是虚构的非官方互动作品；台词不代表任何真实人物的真实发言。头像为原创占位图形，不使用官方品牌素材。内容以已确认文档为准，不添加恋爱、排他关系、说教、好感度、章节或结局界面。

## 本地运行

使用 Node.js 22.12 或更新版本（推荐 Node.js 22，见 `.nvmrc`）。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

开发地址由终端显示。生产构建输出到 `dist/`。浏览器无需访问任何外部接口即可完成聊天。不要直接双击 HTML；请使用开发或预览服务器。

在 Cloudflare 的 Workers & Pages 中打开此 Pages 项目，确认 Git 仓库连接和上述构建设置。推送到生产分支后，Pages 自动构建并发布；其他分支可生成预览部署。确认部署状态为成功后打开网站验证。构建成功与线上发布成功是两个独立步骤。

项目只有一个页面，不使用客户端路径路由，不需要重写规则。资源使用 Vite 的根路径配置，适用于 Pages 根域名，不要设置为 `/my-first-site/`（那是另一种托管路径）。部署后请测试手机、刷新续聊和 `?reset=true`。

原仓库是 Workers 静态模板，其配置备份位于 `docs/original-wrangler.jsonc`。本项目采用用户指定的 Pages Git 自动部署，不需要 Wrangler 或任何 Workers 绑定。旧 `public/index.html` 已由根目录 Vite 入口替代。

建议日常修改先推送功能分支，在 Pages 预览地址确认后合并到 `main`。提交源代码、配置与锁文件；不要提交 `node_modules/`、`dist/`、令牌或本地环境文件。

## 剧情和交互

共 352 句台词、11 处三选一（Q1–Q10 与最后 Q11，共 33 分支）。各分支均汇流。固定回复也以单个候选项出现，需要选择后手动发送。可在发送前切换选择；禁止自由输入。Q7C 一次发送两条原文气泡。唯一条件记忆是 Q6A：提交“我今天也挺累的”才设置 `userTired=true`，结尾触发关心回收；B/C 为 false。

首句在时间标记后约 800 毫秒出现。短消息约 0.7–1 秒，较长消息 1.7–2.4 秒显示输入状态。文档明确的 2、3、4、5 秒停顿单独执行；紧随其后的消息不再叠加延迟。未明确长度的停顿为 2 秒。后台页面暂停剩余时间，返回后继续，不追赶批量消息。22:36 与 23:18 是故事时间。

顶部和底部固定，中间记录独立滚动。距底部 80px 内跟随消息；上翻历史时保留位置，并显示新消息入口。发送自己的回复时回到底部。结束自然停留在“拜拜”，无结束页或重开按钮。

## 保存、重置与修改剧情

存档键为 `today-chat:v1`。每次事件提交、候选选择及页面离开/进入后台时保存。保存合法事件日志、草稿和剩余等待时间；恢复时从剧情图重放已提交事件，重建消息、选择、游标、记忆和结束状态，避免信任损坏的消息或标志。草稿恢复后仍需手动发送。非法/不兼容存档会安全新开，存储被禁用时提示并继续内存运行。

访问 `https://my-first-site-pages.pages.dev/?reset=true` 可清除本项目存档，参数随后从地址栏移除。只清除此键，不清理同域其他数据。进度仅在同一浏览器、同一域名保存，不跨设备同步；清理浏览器数据会丢失记录。

修改剧情可编辑 `docs/dialogue-source.txt` 的剧情段，再执行 `python3 scripts/import-story.py` 并运行测试。大幅修改结构时同步更新导入脚本；发布不兼容剧情必须提升 `src/data/conversation.json` 的 version，避免旧游标错配。不要直接把台词放进 JSX。
